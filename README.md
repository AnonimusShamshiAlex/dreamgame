# Dream Live (Weirdcore / Dreamcore)

3D-мир от первого лица в стиле dreamcore/weirdcore. Это уже не просто
прототип — играбельный мир с хабом, пятью локациями (пляж, цирк, странный
мир-лабиринт, красный город с паркуром, корпоративная башня), погодой,
машиной, поездом со станцией, жилым районом с NPC и лесом.

## Управление

- **На телефоне**: левая половина экрана = виртуальный джойстик (ходьба),
  правая половина = палец = поворот камеры, кнопка **ПРЫЖОК** — нижний
  левый угол.
- **В поезде**: подойдите к станции, когда поезд стоит — сядете
  автоматически. Кнопка ПРЫЖОК — выйти.
- **На компьютере (для проверки в Godot Editor)**: W/A/S/D — ходьба,
  мышь — поворот камеры (кликните, чтобы "захватить" курсор), Space —
  прыжок / выход из поезда.

## Быстрая проверка (самый простой способ)

1. Скачайте бесплатный **Godot 4.3** на godotengine.org/download
   (устанавливать не нужно, просто исполняемый файл).
2. Откройте Godot → Import → выберите `project.godot` из этой папки.
3. Нажмите **Play** (кнопка-треугольник сверху) — мир откроется прямо на
   компьютере, можно походить мышкой и клавиатурой.

## Сборка Android APK

Через `codemagic.yaml` в этой же папке — так же, как раньше: загрузите
проект на GitHub, в Codemagic запустите workflow "Dream Live - Android".
Готовый `.apk` появится в разделе Artifacts.

## Что есть в мире

- **Хаб** — стартовая точка, шоумен (летает, бродит, задаёт загадки при
  приближении), розовая дверь-портал, розовый накренённый дом, радужная
  арка, парящие глаза в небе.
- **Пляж** (север) — песок, пальмы, зонтики, 5 ракушек для сбора,
  погоня тенью-монстром рядом.
- **Цирк** (восток) — загадка с цветными постаментами в правильном
  порядке.
- **Странный мир / лабиринт** (северо-восток) — настоящий проходимый
  лабиринт с выходом; внутри гонится "сосед с лопатой", который реально
  бегает по коридорам, а не сквозь стены.
- **Красный город + паркур** (юг) — прыжки по платформам на высоту.
- **Корпоративная башня** (запад) — пустой офис с рядами компьютеров
  внутри, заходится через дверь снаружи.
- **Жилой район** — дома вдоль дорог, у каждого свой житель-NPC.
- **Поезд** — ездит по кругу через весь мир, останавливается на станции
  у хаба, можно сесть и прокатиться.
- **Лес** (юго-запад) — сосны, одно перевёрнутое дерево, светящийся шар
  и надпись "ты не один".
- **Погода** — дождь то начинается, то заканчивается сам по себе,
  облака плывут по небу.
- Фоновая атмосферная музыка — генерируется прямо в игре, без файлов.

## Файлы проекта

- `scripts/Main.gd` — весь мир строится здесь кодом: окружение, свет,
  локации, машина, поезд, дома, NPC, погода.
- `scripts/Player.gd` — контроллер игрока от первого лица.
- `scripts/MonsterAI.gd`, `scripts/NPCWander.gd`, `scripts/ShowmanAI.gd` —
  поведение монстра, обычных NPC и шоумена.
- `scripts/AmbientMusic.gd` — процедурная фоновая музыка.
- `textures/` — фотографии, вставленные прямо в игру как вывески/двери.
- `scenes/Main.tscn` — стартовая сцена (почти пустая, просто подключает
  Main.gd).
